# Sample data

`sample_usage.csv` is synthetic. It was generated by `tools/generate_sample.py` with a fixed seed, so it is the same every run.

It describes no real organization, team or person. Team names (`team-alpha` and so on) and user ids (`u001` and so on) are made up. The teams were given different usage patterns on purpose, so the report has something to show.

Regenerate it from the repo root:

```bash
python tools/generate_sample.py
```
